# Практика 7 — Рекомендательные системы

## Что делает программа:

1. Загружает MovieLens — оценки пользователей и сведения о фильмах.
2. Делит данные по времени на обучение, валидацию и тест.
3. Запускает пять методов: популярные фильмы, TF-IDF, SVD, ALS и Item-kNN.
4. Подбирает число факторов для SVD и ALS на валидации.
5. Рекомендует пользователям фильмы, исключая уже оценённые.
6. Считает точность, полноту, MAP, NDCG, покрытие каталога и разнообразие рекомендаций.
7. Сохраняет таблицы, рекомендации и графики в results/

## Запуск

Python **3.12**, Windows/Linux. Команды выполняются из этой папки.
Данные уже приложены, поэтому для повторного расчёта интернет не нужен.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe recsys.py --evaluate
```

В текущей папке окружение `.venv` уже подготовлено. Достаточно последней команды.
На Linux вместо `.\.venv\Scripts\python.exe` используйте `.venv/bin/python`.

```powershell
# Отдельная модель, дополнительные значения K
.\.venv\Scripts\python.exe recsys.py --model svd --k 5 10 20 --output results_svd

# Проверки
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe verify_results.py
```

CLI: `--dataset movielens`, `--model all|popular|content|svd|als|item_knn`,
`--k 5 10`, `--seed 42`, `--data data`, `--output results`, `--evaluate`.
Оценка выполняется всегда; `--evaluate` принят для совместимости с примером лекции.
K=5 и K=10 включены всегда, дополнительные K добавляются.
Отчёт сформирован один раз для основного эксперимента с seed=42 и сохранён в `reports/`.
При запуске кода пересчитываются результаты и графики

## Постановка и защита от утечки

Датасет: **100 836 оценок, 610 пользователей, 9 742 фильма**, шкала 0,5–5.
Положительное взаимодействие и тестовая релевантность: **rating ≥ 4**.
Набор загружен из [официального источника](https://grouplens.org/datasets/movielens/latest/).
Исходные файлы, архив и лицензионный README находятся в `data`.
Название `latest` не гарантирует постоянство содержимого; для воспроизведения используйте
приложенный снимок и `data/manifest.json`, а не новую загрузку.

1. Глобальная временная сортировка; границы около 80%/90%, одинаковые timestamp
   остаются вместе. Обучение — 80 668, валидация — 10 084, тест — 10 084 оценки.
2. Факторы SVD/ALS: 20, 50, 100. Выбор по NDCG@10 активных пользователей валидации,
   затем переобучение на train+validation. Оба метода выбрали 100 факторов.
3. Кандидаты — 8 586 фильмов, наблюдавшихся до теста. Все ранее оценённые фильмы
   исключаются; выборки отрицательных кандидатов нет.
4. 652 положительных взаимодействия с новыми фильмами **сохраняются в знаменателях**.
   Они недостижимы для выбранного общего каталога.
5. Оцениваются 72 пользователя с непустым множеством тестовых оценок ≥4.
   Ещё два пользователя не включены в средние. Метрики доступны для cold=0,
   short=1–19 и active≥20 обучающих оценок; размеры групп 47, 2 и 23.
6. При отсутствии истории используется популярное. Для TF-IDF, ALS и Item-kNN
   fallback применяется также при отсутствии положительной истории.
7. Контент — название и жанры. Пользовательские теги из будущего не используются.
   Тексты и IDF берутся только из обучающего каталога. Внутри тестового периода
   история не обновляется.

## Модели

| Модель | Реализация |
|---|---|
| Популярное | Число положительных обучающих оценок |
| TF-IDF | `TfidfVectorizer`, средний профиль понравившихся фильмов, косинус |
| SVD | `surprise.SVD`, явные оценки, векторизованный прогноз без clipping |
| ALS | `implicit.cpu.als.AlternatingLeastSquares`, бинарные предпочтения, confidence=21 |
| Item-kNN | Косинус по аудиториям фильмов, 50 соседей, сумма по положительной истории |

ALS и Item-kNN работают с **бинаризацией реальных оценок**, а не с настоящими логами
просмотров. Это явно описано в отчёте. В слайдах ALS приведён в блоке item-based,
но факторизация и поиск соседей — разные методы; здесь реализованы оба.

## Основные результаты (K=10, 72 пользователя)

| Модель | Precision | Recall | MAP@10 | NDCG | Покрытие |
|---|---:|---:|---:|---:|---:|
| Популярное | 0,2625 | 0,0706 | 0,1950 | 0,2926 | 0,85% |
| TF-IDF | 0,2319 | 0,0592 | 0,1744 | 0,2599 | 1,36% |
| SVD | 0,2514 | 0,0653 | 0,1849 | 0,2829 | 1,51% |
| ALS | 0,2653 | 0,0665 | 0,1956 | 0,2987 | 2,32% |
| Item-kNN | 0,2653 | 0,0720 | 0,1909 | 0,2958 | 1,37% |

У 47 пользователей нет обучающей истории, поэтому среднее в значительной мере
определяется одинаковым fallback. Среди active лучший NDCG@10 у Item-kNN (0,1023).
Парный bootstrap по пользователям, 2 000 повторов: 95% интервал разницы ALS с
популярным **[-0,0286; 0,0382]**, поэтому превосходство не установлено.
Подробные ограничения и качественный разбор пользователей 414 и 511 — в отчёте.

Метрики усредняются по пользователям. AP@K нормируется на `min(K, |R_u|)`;
MAP — среднее AP@K. NDCG использует бинарную релевантность. Coverage — уникальные
рекомендации / 8 586. Diversity — среднее попарное расстояние Жаккара по жанрам.
`genre_novelty` — доля рекомендаций с новым для положительной истории жанром;
для cold не определена (пустая ячейка CSV), в общее среднее не включается.

## Структура

```text
recsys.py                 CLI и полный эксперимент
recommender/data.py       загрузка, валидация входа, временной сплит
recommender/models.py     пять моделей с fit/recommend
recommender/metrics.py    метрики ранжирования и разнообразия
recommender/experiment.py валидация, оценка, bootstrap, графики и экспорт
verify_results.py        независимая сверка сохранённых артефактов
tests/                   11 проверок математических и поведенческих свойств
data/                    исходный MovieLens с условиями использования
results/                 таблицы, JSON, графики, протоколы
reports/                 готовый отчёт Word, PDF, Markdown
```

Время обучения в `summary.json` не включает общий `Context` и построение TF-IDF;
это не полная стоимость моделей. Повторный запуск побайтово воспроизвёл восемь
табличных/JSON артефактов. Время исполнения естественно меняется.
